 Java To-Do List

 📌 Project Description

This is a simple console-based To-Do List application built using Java.
The program allows users to manage their daily tasks by adding, viewing, and deleting tasks from a list.

 🛠 Technologies Used

* Java
* VS Code

 ▶️ How to Run the Project

1. Clone the repository.
2. Open the project folder in VS Code.
3. Compile the program using:
   javac TodoList.java
4. Run the program using:
   java TodoList

 🎯 Features

* Add new tasks
* View all tasks
* Delete tasks from the list
* Menu-driven console interface

 📚 Concepts Used

* ArrayList
* Scanner class
* Loops
* Conditional statements
* Menu-driven programming
